# История изменений

Все значимые изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [1.0.3] - 2025-10-30

### Добавлено
- **Генератор агентов** с командой `bundle exec mcp_agent init`
  - Автоматическое создание всей структуры проекта
  - Автоматическое создание или обновление `Gemfile` с нужными зависимостями
  - Создание `config/settings.yml` с подробными комментариями
  - Создание главного файла агента (по умолчанию `agent.rb`)
  - Создание скрипта `credentials.rb` для управления секретами
  - Автоматическая настройка `.gitignore`
  - Поддержка пользовательских названий: `bundle exec mcp_agent init my_bot`
- Шаблоны файлов в директории `templates/`
  - `templates/Gemfile` - готовый Gemfile с правильными зависимостями
  - `templates/settings.yml` - конфигурация с комментариями
  - `templates/agent.rb` - готовый к запуску главный файл
  - `templates/credentials.rb` - скрипт управления credentials

### Изменено
- Упрощен процесс создания агента с 7 шагов до 6
- Обновлена документация в README с новой инструкцией по быстрому старту
- CLI команда `init` теперь основная для создания новых агентов
- Команда `install_credentials` оставлена для обратной совместимости
- Пользователю больше не нужно вручную редактировать Gemfile

### Улучшено
- **Время создания агента сокращено с 5 минут до 2 минут**
- Пользователю больше не нужно вручную создавать или редактировать файлы
- Генератор умеет обновлять существующий Gemfile, добавляя только mcp_agent
- Все шаблоны имеют подробные комментарии
- Единообразная структура для всех создаваемых агентов

## [1.0.2] - 2025-10-30

### Добавлено
- **Интегрированная система управления credentials** с шифрованием в стиле Rails
  - Модуль `McpAgent::Credentials` для управления зашифрованными credentials
  - Совместимость с Rails `ActiveSupport::EncryptedConfiguration`
  - Единый скрипт `credentials.rb` с командами `edit` и `show`
  - Автоматическое шифрование/расшифровка credentials с использованием `config/master.key`
  - Генератор шаблонов `McpAgent::Generator.install_credentials_scripts`

### Изменено
- Агент теперь поддерживает три источника credentials (в порядке приоритета):
  1. Зашифрованный `config/credentials.yml.enc` (рекомендуется)
  2. Прямые credentials в `config/settings.yml`
  3. Переменные окружения
- Добавлена зависимость `activesupport` для зашифрованных credentials

### Улучшено
- Повышена безопасность с помощью зашифрованного хранения credentials
- Унифицированное управление credentials для всех агентов
- Автоматическое управление `.gitignore` для `config/master.key`
- Подробное руководство и документация по credentials
- Единый скрипт вместо двух отдельных для удобства использования

## [1.0.1] - 2025-10-29

### Исправлено
- Исправлен конфликт переменной окружения RUBYOPT в методах Credentials.edit и Credentials.show
  - Добавлена автоматическая очистка RUBYOPT для предотвращения ошибок "invalid switch in RUBYOPT"
  - Credentials теперь доступны через удобные скрипты: `./credentials_edit.rb` и `./credentials_show.rb`

### Изменено
- Добавлены исполняемые скрипты для управления credentials
- Обновлена вся документация с учетом нового именования

## [1.0.0] - 2025-01-29

### Добавлено
- Первый релиз McpAgent gem
- Универсальный фреймворк агентов с поддержкой MCP сервера
- Динамическая загрузка инструментов из любого MCP сервера
- Транспортный слой: Telegram Bot и RabbitMQ
- AI обработка с OpenAI
- Безопасное управление credentials с шифрованием AES-256-GCM
- Модульная архитектура с переиспользуемыми компонентами
- Комплексная обработка ошибок и логирование
- Конфигурация через YAML файлы
- Поддержка нескольких одновременных транспортов

### Возможности
- **Agent Base**: Базовая функциональность агента с настраиваемыми system prompts
- **MCP Client**: Динамическое подключение к любому MCP-совместимому серверу
- **Транспорты**: 
  - Telegram Bot с поддержкой markdown
  - RabbitMQ для межагентного взаимодействия (фреймворк готов)
- **Credentials**: Система зашифрованных credentials в стиле Rails
- **AI интеграция**: Интеграция с OpenAI с настраиваемыми моделями
- **Обработка ошибок**: Централизованная обработка ошибок со структурированным логированием

### Документация
- Полный README с руководством по быстрому старту
- Примеры конфигураций
- API документация в комментариях кода
